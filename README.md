# 💐 Compliment Wall

A virtual wall where people can leave, discover, and share compliments.

The project started as a playful way to recreate the feeling of a physical compliment wall in a virtual space. It is open for contributions, so feel free to add your own ideas, improvements, and creative touches.

## ✨ Features

- 💌 Leave a compliment on the shared wall
- 🌸 Browse compliments from others
- 👤 Choose whether to post anonymously or with your name
- 🎨 Interactive, animated compliment cards
- 📱 Responsive design for mobile and desktop

More features and ideas are welcome!

## 🛠️ Built With

- **Framework:** Next.js
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Backend:** Convex

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/changach-3000/compliment-wall.git
cd compliment-wall
npm install
```
### 2. Set up environment variables

Create a `.env.local` file in the root of the project.

You will need the Convex environment details to run the project locally. These will be provided to contributors separately.

Your `.env.local` should contain the required Convex variables, for example:

```env
NEXT_PUBLIC_CONVEX_URL=your_convex_url
```
### 3. Start the development server
```Bash
npm run dev
```
